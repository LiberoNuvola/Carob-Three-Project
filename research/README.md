# Research

This directory records evidence used to evaluate Carob Three.

Recommended sections:

- `prior-art/` — prior systems, papers, patents, and public projects
- `plant-communication/` — plant signalling, electrophysiology, sensing, and communication
- `citizen-science/` — participatory observation and contributor validation
- `ai/` — AI/ML interpretation and decision support
- `provenance/` — provenance, attribution, identity, and rewards

Research notes must distinguish:

1. source-derived facts;
2. project interpretation;
3. unresolved hypotheses.
